# FGFE / TONFARM migration

Рабочая ветка: `agent/tonfarm-split-pages`.

Структура проекта:

- `web/` — интерфейс Telegram Mini App, игры, изображения и отдельные страницы.
- `bac/` — Flask + Socket.IO backend, бот и бизнес-логика.
- `data/` — runtime-хранилище и локали.

Отдельные страницы:

- `/` — Главная
- `/profile` — Профиль
- `/bonus` — Бонусы / стейкинг
- `/settings` — Настройки

Навигация делает настоящий переход между URL и сохраняет query-параметры Telegram. Каркас блоков отображается сразу, затем пользовательские данные, история, кошелек, игры и бонусы загружаются параллельно.

Секреты `BOT_TOKEN` и `CRYPTO_PAY_TOKEN` должны задаваться переменными окружения на сервере и не публикуются в открытом репозитории.

Важно: GitHub Pages не запускает Flask/Socket.IO. Для полного функционала backend из `bac/` должен работать на сервере.
