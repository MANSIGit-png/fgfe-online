01 / О проекте

Сделано, чтобы
работать быстро.

Сайт построен на чистых HTML, CSS и JavaScript. Никаких тяжёлых библиотек и лишних запросов — только то, что нужно пользователю.

Структура уже подготовлена для размещения на GitHub Pages и подключения собственного домена.

04 / FAQ

Коротко о главном.

Сайт работает на телефоне?

Да. Интерфейс полностью адаптивный и перестраивается под небольшие экраны.

Можно подключить fgfe.online?

Да. Для GitHub Pages нужно указать домен в настройках Pages и направить DNS-записи домена на GitHub.

Можно потом добавить новые функции?

Да. Текущая версия — чистая база, которую можно расширять страницами, формами, авторизацией и серверной частью.
